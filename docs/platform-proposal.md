# Proposal: Northern Cape pilot to national ICT ecosystem service

**Status:** discussion proposal

## Executive summary

Commission a focused pilot that establishes a trusted Northern Cape ICT ecosystem baseline, puts the platform's governance workflow into daily use, and leaves a repeatable path for national scale.

The platform replaces fragmented lists with a maintained public service: a searchable map and directory, accountable verification, public publication, and operational controls for the teams responsible for keeping the picture current.

## Proposed scope

### 1. Discovery and alignment

Confirm decision owners, priority users, source systems, terminology, geography and publication policy.

### 2. Data and verification

Ingest priority datasets, reconcile duplicates, capture provenance and run a repeatable review and verification campaign.

### 3. Platform operations

Configure roles, workflows, notifications, audit, backups and service ownership for a dependable operating rhythm.

### 4. Adoption and insight

Train users, publish the first public brief, measure usage and turn map data into opportunity and coverage insight.

## Primary deliverables

- Validated Northern Cape ecosystem baseline with source and verification status
- Public map, organisation directory and printable system book configured for the agreed scope
- Contributor, reviewer and administrator operating playbook
- Data-quality register covering gaps, duplicates, stale records and follow-up actions
- Launch dashboard with agreed adoption, data-quality and service measures
- Scale-ready national onboarding plan for the remaining provinces

## Indicative 90-day sequence

| Phase | Timing | Outcome |
| --- | --- | --- |
| Align | Days 1–20 | User journeys, source inventory, data contract, governance decisions and success baseline |
| Build and verify | Days 21–60 | Reconciled priority records, configured workflows, verification campaign and launch content |
| Launch and transfer | Days 61–90 | Published baseline, user training, measures review, operations documentation and scale backlog |

## Success measures

- **Coverage:** priority towns, organisations and opportunity categories represented against the agreed baseline.
- **Quality:** published records have provenance, an accountable owner and a review or verification status.
- **Adoption:** target teams use the map and directory in planning, referrals, sourcing and reporting.
- **Sustainability:** named owners, review cadence, backup controls and an expansion backlog are in place.

## Decisions needed to start

1. Name the accountable sponsor and day-to-day product owner.
2. Confirm the first priority users, municipalities and ecosystem categories.
3. Approve the source and verification policy for public records.
4. Agree the pilot review cadence and acceptance measures.

## Commercial note

This is a discussion proposal, not a binding quotation. Delivery fee, hosting model, support level, data-ingestion effort and any national expansion phase should be priced after the discovery session confirms the baseline and responsibilities.

## Recommended next step

Book a 60-minute discovery session. Select the pilot user group, confirm the first source inventory and leave with a named owner for each decision. The output is a short statement of work and a delivery calendar.
