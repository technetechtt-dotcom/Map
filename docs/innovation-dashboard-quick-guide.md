# Provincial Innovation Dashboard — quick guide

## Public view
Open **/innovation-dashboard** for the Northern Cape public innovation dashboard. It shows only published ecosystem information and provides public KPIs for locations, organisations, funding, programmes, events and procurement together with district-level geographic coverage.

## Restricted view
Authorised stakeholders and administrators sign in and use **/dashboard** for tenant-scoped analytics. Repository metrics are included in the authenticated analytics totals. Operators can continue into the Ops console for data quality, submissions, intelligence, audit and repository administration.

## Repository workflow
1. Sign in and open **Account → Innovation Repository**.
2. Search existing stakeholder documents.
3. Upload a PDF, Office document or approved image.
4. Add title, description, category and tags.
5. Select organisation, province-wide, all-stakeholder or stakeholder-group access as permitted by role.
6. Open/download documents directly from the repository; private downloads are re-authorised on every request.

## Interpreting dashboard figures
Public figures are derived only from records in published state. Repository files are private knowledge-management assets and are not counted as public ecosystem entities. Data-quality and verification status should therefore be reviewed separately in Ops before external reporting.
